# WMerge — сравнение и слияние файлов и папок, как WinMerge

Цель: WinMerge на macOS. Вид — один в один с оригиналом (решение человека 21.11.2026), кроме того,
что диктует система: рамка и скругления окна, строка меню сверху экрана.

Образцы: сайт <https://winmerge.org>, руководство <https://manual.winmerge.org/en/>, исходники
(`Src/Merge.rc` — меню и строки, `OptionsDiffColors.cpp` — цвета). Снимки программы для сверки —
`reference/`.

## Решения

- **Стек:** Swift + AppKit, SwiftPM без Xcode, как у WExplorer, WTaskbar, WPhoto и WTortoise.
  `scripts/bundle.sh` собирает `build/WMerge.app`, `scripts/make-dmg.sh` — образ. macOS 14+.
- **Масштаб:** снимки оригинала сняты при 150 %, поэтому размеры в пунктах — пиксели снимка / 1,5:
  панель инструментов 27, значки 20, строка текста 15, заголовок панели 19, строка списка папок 16.
- **Всё рисуется своим кодом**, стандартных элементов AppKit в окне нет: панель инструментов,
  вкладки, полосы прокрутки, кнопки, флажки, поля со списком, список папок. Иначе вид Windows не
  получить. Обычный AppKit — только в диалогах (поиск, переход, настройки) и в системных панелях.
- **Значки — свои, по образцу оригинала** (`Shared/Glyphs.swift`, сетка 32×32): те же образы и цвета.
  Картинки WinMerge не взяты — они под GPL, проект под MIT, как и соседние. Если нужна точность до
  пикселя, путь один: взять оригинальные значки и перевести проект на GPL — решение за человеком.
- **Шрифт текста — Menlo 11:** родственник шрифта со снимков оригинала (DejaVu Sans Mono).
  Интерфейс — системный 11,5 (Segoe UI в системе нет, шрифты Microsoft не берём).
- **Цвета отличий** — умолчания WinMerge: отличие `EFCB05`, пустая сторона `C0C0C0`, выбранное
  `EF7774` / `F0C0C0`, отличие в строке `F1E2AD` / `FFA0A0`, игнорируемое `FBF2BF`; в списке папок
  разное `F0DE7D`, только с одной стороны `DDDDDD`. Подсветка синтаксиса — цвета редактора WinMerge.
- **Движок сравнения свой** (`Diff/Engine.swift`): Майерс в линейной памяти по строкам, ключ строки
  учитывает настройки (пробелы, регистр, концы строк). Внутри отличия похожие строки ставятся друг
  против друга (как на снимке оригинала: `{` — заполнитель, изменённая строка — напротив своей).
  Отличия внутри строки — тем же Майерсом по словам.
- **Документ** (`Diff/CompareDocument.swift`): две стороны, строки хранят свои концы (`\n`, `\r\n`,
  `\r`), так что смешанные концы строк переживают сохранение. Отмена — снимками обеих сторон
  (массивы Swift копируются лениво), набор текста подряд — один шаг.
- **Пересравнение после каждой правки** сразу, без задержки (у WinMerge автопересравнение — настройка).
  На очень больших и очень разных файлах набор может подтормаживать — см. «Дальше».
- **Клавиши:** Ctrl оригинала → ⌘, Alt → ⌥. `⌥↓ ⌥↑` — следующее и предыдущее отличие, `⌥→ ⌥←` —
  копировать, F5, F7/F8, F4, F3, F6 — как в оригинале. Из-за этого `⌥←/→` не ходят по словам.
- **Язык интерфейса — английский, строки дословно из WinMerge.** Русский выбирается в настройках, но
  переведено пока только окно «О программе»: человек просил копию оригинала, а не перевод.
- **Проверка:** `WMerge -selftest` — движок и слияние на случайных текстах; `WMerge -snapshot <папка>`
  — окна в PNG (со своими образцами или `-left … -right …`).

- [x] Сравнение файлов: две панели с общей прокруткой, заголовки с путём и `*`, панель расположения,
      панель отличия, строки состояния (Ln / Col / Ch, кодировка, концы строк, RO)
- [x] Отличия: строки-заполнители, отличия внутри строки, выбранное отличие, подсветка синтаксиса
- [x] Слияние: Copy to Right / Left, and Advance, Copy All, переходы First / Previous / Next / Last /
      Current, двойной щелчок выбирает отличие
- [x] Правка текста в панелях: набор, выделение мышью и клавишами, буфер обмена, отмена и возврат,
      Find / Replace (регулярные выражения), Go to (строка или отличие), Select Line Difference
- [x] Сохранение (Save, Save Left / Right, As), запрос при закрытии с выбором по каждой стороне,
      Reload, Read-Only, Convert Line Endings, Swap Panes, Zoom
- [x] Настройки сравнения: пробелы (сравнивать / игнорировать изменения / все), пустые строки,
      регистр, концы строк — в Options и в списке у кнопки Options
- [x] Сравнение папок: дерево и плоский список, колонки как в оригинале, сортировка, цвета строк,
      значки состояния, фильтры Show …, копирование влево / вправо, удаление в Корзину, контекстное меню
- [x] Кодировки: UTF-8 (с BOM и без), UTF-16 с BOM, Windows-1251 / 1252; сохранение в исходной
- [x] Пункт «WMerge» в контекстном меню WExplorer (на его стороне — `Operations/MergeMenu.swift`): договор —
      ссылка `wmerge://compare?path=…&path=…` и идентификатор `dev.oleg.wmerge`. Без путей — пустое окно
      выбора, один путь — он слева, два — сразу сравнение (`MainWindowController.openFromExplorer`)
- [x] Generate Patch (unified diff), запуск из командной строки `WMerge левый правый`, иконка, dmg
